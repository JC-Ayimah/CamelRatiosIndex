# Changelog

## CamelRatiosIndex (development version)

### CamelRatiosIndex 1.1.0.9000

- Added Interactive shiny dashboard
  ([`launch_dashboard()`](https://JC-Ayimah.github.io/CamelRatiosIndex/reference/launch_dashboard.md))
  for non programmatic users.
- Added export functionalities within dashboard: download index tables
  as CSV, Factor Analysis and Data Explorer
- Added examples on how to perform year-on-year trend analysis in
  vignette
- Enhanced visualisation options in the dashboard using `plotly` for
  interactive charts (zoom, pan, tooltips)
